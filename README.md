## About

Modern AI agents need more than language models to work effectively with websites and web applications.

They need browser access, developer tools, documentation retrieval, reusable skills, testing capabilities, integrations, and standardized protocols.

**Awesome Web Agent Ecosystem** brings these resources together in one community-curated directory.

## Featured Resources

A starting selection of useful projects and standards.

### MCP and browser tooling

- [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) — Connect coding agents to Chrome DevTools for browser inspection, debugging, automation, and performance analysis.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) — Browser automation through Playwright's Model Context Protocol server.
- [Model Context Protocol](https://modelcontextprotocol.io/) — Open protocol for connecting AI applications to external tools and data sources.
- [Context7](https://github.com/upstash/context7) — Up-to-date documentation context for AI coding assistants.
- [Firecrawl](https://github.com/firecrawl/firecrawl) — Web crawling and extraction infrastructure for AI applications.

### Browser agents

- [Browser Use](https://github.com/browser-use/browser-use) — Browser automation designed for AI agents.
- [Stagehand](https://github.com/browserbase/stagehand) — Browser automation framework with AI-oriented interactions.
- [Skyvern](https://github.com/Skyvern-AI/skyvern) — Browser automation for complex web workflows.

### Agent skills

- [Agent Skills Specification](https://agentskills.io/) — Open format for packaging reusable agent instructions and workflows.
- [Agent Skills Repository](https://github.com/agentskills/agentskills) — Specification and documentation for Agent Skills.
- [Anthropic Skills](https://github.com/anthropics/skills) — Example skills and implementations for Claude.
- [Vercel Skills](https://github.com/vercel-labs/skills) — CLI and ecosystem for discovering and installing agent skills.

### Deployment and design integrations

- [Vercel MCP](https://vercel.com/docs/agent-resources/vercel-mcp) — Official MCP server for Vercel projects, deployments, documentation, and logs.
- [Netlify MCP](https://github.com/netlify/netlify-mcp) — Official MCP server for managing Netlify projects and deployments.
- [Figma MCP Server](https://developers.figma.com/docs/figma-mcp-server/) — Official integration for bringing Figma design context into AI workflows.

### Documentation and research

- [MDN Web Docs](https://developer.mozilla.org/) — Reference documentation for web technologies.
- [Chrome for Developers](https://developer.chrome.com/docs/) — Chrome platform and developer tooling documentation.
- [web.dev](https://web.dev/) — Guidance and resources for building modern web experiences.
- [Crawl4AI](https://github.com/unclecode/crawl4ai) — Open-source web crawling and extraction for AI workflows.
- [Jina Reader](https://jina.ai/reader/) — Web content extraction and conversion for AI applications.

See the individual category pages for more resources.

## Scope

This repository focuses on the tools, protocols, and integrations that enable AI agents to work with the web.

### Included

- Model Context Protocol servers for web development and browser interaction.
- Browser agents and automation frameworks.
- Reusable agent skills and workflows.
- Web documentation retrieval and indexing tools.
- Design-tool and developer-tool integrations.
- Browser debugging, testing, and accessibility tools.
- Web research, crawling, and extraction infrastructure.
- Deployment and hosting integrations.
- Protocols and standards relevant to agentic web workflows.

### Not included

This is not a general frontend UI-library directory.

The following belong in a dedicated frontend resource collection:

- Standalone React, Vue, Svelte, and Angular component libraries.
- CSS frameworks and styling utilities.
- Icon, font, illustration, and asset collections.
- Design systems and component showcases.
- Generic website templates and landing-page collections.
- Design inspiration galleries and general frontend tutorials.

For frontend implementation resources, see [Agentic Frontend Playbook](https://github.com/axomiyaindie/agentic-frontend-playbook).
