# Protocols and Standards

Specifications and protocols that enable AI agents to interact with tools, browsers, websites, and external systems.

- [Model Context Protocol](https://modelcontextprotocol.io/) — Standard for connecting AI applications to external tools and data sources.
- [Agent Skills](https://agentskills.io/) — Open format for packaging reusable agent knowledge and workflows.
- [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) — Protocol for controlling and inspecting Chromium-based browsers.
- [WebDriver](https://www.w3.org/TR/webdriver2/) — W3C standard for browser automation.
- [WebDriver BiDi](https://w3c.github.io/webdriver-bidi/) — Bidirectional browser automation protocol.

## Submission notes

Prefer primary specifications and official documentation. Clearly distinguish stable standards, drafts, proposals, and vendor-specific implementations.
