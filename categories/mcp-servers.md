# MCP Servers

Model Context Protocol servers that expose web-related tools, browser capabilities, documentation, and integrations to AI applications.

## Browser and developer tools

- [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) — Browser inspection, debugging, automation, and performance analysis through Chrome DevTools.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) — Browser automation capabilities exposed through MCP.

## Web research and extraction

- [Firecrawl](https://github.com/firecrawl/firecrawl) — Web crawling and extraction infrastructure with MCP integration.
- [Context7](https://github.com/upstash/context7) — Documentation retrieval for AI coding assistants.

## Design integrations

- [Figma MCP Server](https://developers.figma.com/docs/figma-mcp-server/) — Official MCP integration for accessing design context and working with Figma files.
- [Figma MCP Server Guide](https://github.com/figma/mcp-server-guide) — Additional setup guidance and resources.

## Deployment integrations

- [Vercel MCP](https://vercel.com/docs/agent-resources/vercel-mcp) — Official remote MCP server for accessing Vercel projects, deployments, documentation, and logs.
- [Netlify MCP](https://github.com/netlify/netlify-mcp) — Official MCP server for creating, building, deploying, and managing Netlify projects.

## Official ecosystem

- [MCP Servers](https://github.com/modelcontextprotocol/servers) — Official collection of example and reference MCP servers.
- [MCP Registry](https://registry.modelcontextprotocol.io/) — Discover MCP servers in the ecosystem.

## Submission notes

Prefer official server repositories. Clearly distinguish official integrations from community-maintained implementations.
