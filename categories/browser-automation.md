# Browser Automation

Frameworks and tools for automating browser interactions, including automation interfaces designed to work with AI agents.

- [Playwright](https://github.com/microsoft/playwright) — Browser automation and end-to-end testing framework.
- [Puppeteer](https://github.com/puppeteer/puppeteer) — JavaScript library for controlling Chrome and other supported browsers.
- [Browser Use](https://github.com/browser-use/browser-use) — Browser automation designed for AI agents.
- [Stagehand](https://github.com/browserbase/stagehand) — Browser automation framework with AI-oriented APIs.
- [Selenium](https://github.com/SeleniumHQ/selenium) — Browser automation ecosystem supporting multiple browsers and languages.
