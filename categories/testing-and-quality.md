# Testing and Quality

Tools and integrations that help agents test web applications, identify defects, validate accessibility, and assess quality.

## Browser testing

- [Playwright](https://github.com/microsoft/playwright) — End-to-end browser testing and automation.
- [Selenium](https://github.com/SeleniumHQ/selenium) — Browser automation and testing ecosystem.

## Accessibility

- [axe-core](https://github.com/dequelabs/axe-core) — Accessibility testing engine for web applications.

## Performance and quality

- [Lighthouse](https://github.com/GoogleChrome/lighthouse) — Audits web application performance, accessibility, SEO, and best practices.

## Submission notes

Describe whether a resource performs automated tests, provides agent interfaces, or supplies reports and diagnostics. Avoid claiming complete accessibility or security compliance based on automated checks alone.
