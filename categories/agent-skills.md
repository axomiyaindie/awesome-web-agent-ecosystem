# Agent Skills

Reusable instructions, workflows, and supporting resources that extend the capabilities of AI agents.

## Standards and specifications

- [Agent Skills](https://agentskills.io/) — Open standard for packaging specialized agent knowledge and workflows.
- [Agent Skills Specification](https://github.com/agentskills/agentskills) — Specification and documentation for the Agent Skills format.

## Skill collections and tooling

- [Anthropic Skills](https://github.com/anthropics/skills) — Example skills and implementations for Claude.
- [Vercel Skills](https://github.com/vercel-labs/skills) — Tooling for discovering and installing agent skills.
- [Vercel Agent Skills](https://github.com/vercel-labs/agent-skills) — Reusable skills for development workflows.
- [Awesome Frontend Skills](https://github.com/finfin/awesome-frontend-skills) — Collection of frontend-focused agent skills.

## What belongs here?

- Reusable `SKILL.md` workflows.
- Skill specifications and validators.
- Skill discovery and installation tools.
- Web development and browser automation skills.
- Practical agent workflow collections.

Always identify platform-specific requirements where applicable.
