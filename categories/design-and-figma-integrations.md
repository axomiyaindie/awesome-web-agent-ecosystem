# Design and Figma Integrations

Tools and integrations that connect AI agents with design files, design workflows, and collaborative design platforms.

- [Figma Developer Platform](https://developers.figma.com/) — Official developer resources for Figma integrations and APIs.
- [Figma MCP Server](https://developers.figma.com/docs/figma-mcp-server/) — Official MCP integration that gives AI agents access to Figma design context and canvas workflows.
- [Figma MCP Server Guide](https://github.com/figma/mcp-server-guide) — Additional setup guidance and resources.
- [Figma Plugin API](https://www.figma.com/plugin-docs/) — Documentation for building Figma plugins.

## What belongs here?

- Design-tool MCP servers.
- Agent integrations for design files.
- Design-to-code workflows.
- Tools for extracting design context and assets.

Do not include standalone design inspiration galleries or ordinary UI component libraries.
