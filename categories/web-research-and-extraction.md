# Web Research and Extraction

Tools for discovering, crawling, extracting, and transforming web content for AI agents and applications.

- [Firecrawl](https://github.com/firecrawl/firecrawl) — Web crawling and content extraction infrastructure for AI applications.
- [Crawl4AI](https://github.com/unclecode/crawl4ai) — Open-source web crawling and extraction framework designed for AI workflows.
- [Jina Reader](https://jina.ai/reader/) — Converts web content into formats suitable for reading and AI workflows.

## What belongs here?

- Web crawling and scraping frameworks.
- Content extraction and conversion tools.
- Search and retrieval integrations.
- Research tools designed for agent workflows.

Submissions must respect website terms, robots policies, copyright, privacy, and applicable laws.
