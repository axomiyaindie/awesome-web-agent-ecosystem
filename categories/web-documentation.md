# Web Documentation

Documentation resources and tools that help agents retrieve accurate technical information about web platforms, APIs, frameworks, and browser technologies.

## Documentation sources

- [MDN Web Docs](https://developer.mozilla.org/) — Reference documentation for HTML, CSS, JavaScript, and web APIs.
- [Chrome for Developers](https://developer.chrome.com/docs/) — Chrome platform, browser, and developer tooling documentation.
- [web.dev](https://web.dev/) — Guidance for building modern web experiences.
- [Playwright Documentation](https://playwright.dev/docs/intro) — Official Playwright documentation.
- [Figma Developer Documentation](https://developers.figma.com/) — Figma APIs and developer integrations.

## Documentation retrieval

- [Context7](https://github.com/upstash/context7) — Supplies up-to-date documentation context to AI coding assistants.

## Submission notes

Prefer authoritative documentation and tools that preserve source links, version context, and attribution.
