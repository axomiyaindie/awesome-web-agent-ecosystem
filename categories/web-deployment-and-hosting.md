# Web Deployment and Hosting

Tools and integrations that allow AI agents to interact with deployment platforms, hosting services, and web infrastructure.

## Official MCP integrations

- [Vercel MCP](https://vercel.com/docs/agent-resources/vercel-mcp) — Official remote MCP server for managing projects, deployments, documentation, and logs.
- [Netlify MCP](https://github.com/netlify/netlify-mcp) — Official MCP server for creating projects, building, deploying, and managing Netlify resources.

## Platforms and developer resources

- [Vercel](https://vercel.com/) — Web application deployment and hosting platform.
- [Netlify](https://www.netlify.com/) — Web development and deployment platform.
- [Cloudflare Developers](https://developers.cloudflare.com/) — Documentation for Cloudflare developer products and infrastructure.

## Scope

This category is intended for:

- Official MCP servers and agent integrations.
- Deployment automation tools.
- Hosting platform APIs and CLIs with agent workflows.
- Infrastructure management tools relevant to web applications.

A hosting platform alone is not an agent integration. Prefer linking to a specific integration or clearly label general platform references.
