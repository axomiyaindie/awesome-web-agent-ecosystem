# Browser Agents

Projects that use AI agents to navigate websites, interact with browser interfaces, and execute multi-step web workflows.

- [Browser Use](https://github.com/browser-use/browser-use) — Browser automation framework designed for AI agents.
- [Stagehand](https://github.com/browserbase/stagehand) — AI-oriented browser automation framework.
- [Skyvern](https://github.com/Skyvern-AI/skyvern) — Automates browser-based workflows using AI and computer vision.

## What belongs here?

- Autonomous browser agents.
- Agents that interpret pages and perform web tasks.
- Browser-based workflow execution systems.
- Projects that combine language models with browser interaction.

Do not list ordinary browser extensions unless they provide meaningful agent capabilities.
