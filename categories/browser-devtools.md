# Browser Developer Tools

Tools that allow agents and developers to inspect, debug, profile, and understand browser behavior.

- [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) — Exposes Chrome DevTools capabilities to AI coding agents.
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) — Official browser debugging and inspection tools.
- [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) — Protocol for instrumenting and controlling Chromium-based browsers.

## What belongs here?

- Browser inspection integrations.
- Network and console debugging tools.
- Performance profiling tools.
- Browser protocol clients.
- Agent interfaces for developer tools.

Clearly identify browser compatibility and any permissions required.
