# Category Guide

This guide explains the scope of each directory category.

| Category | Include |
|---|---|
| MCP Servers | MCP servers and integrations for web-related tools |
| Browser Agents | AI agents that interpret and operate websites |
| Browser Automation | Browser automation frameworks and interfaces |
| Agent Skills | Reusable agent instructions, workflows, and skill tooling |
| Web Documentation | Technical documentation and documentation retrieval |
| Design & Figma Integrations | Agent integrations for design tools and files |
| Frontend Development Workflows | Agent products, frameworks, skills, and integrations that materially support frontend engineering |
| Testing & Quality | Browser testing, accessibility, and quality assurance |
| Web Research & Extraction | Crawling, extraction, and web research |
| Browser DevTools | Inspection, debugging, and browser performance tools |
| Web Deployment & Hosting | Agent integrations for deployment and hosting |
| Protocols & Standards | Agent, browser, and interoperability standards |

## Avoiding overlap

A project may fit more than one category. Prefer the category that best represents its primary purpose.

Use cross-links when a resource has a genuinely useful secondary role. Avoid unnecessary duplication.

## Out of scope

Standalone UI component libraries, CSS frameworks, design systems, component showcases, icon and font collections, generic website templates, and design inspiration resources are outside this repository's scope.
