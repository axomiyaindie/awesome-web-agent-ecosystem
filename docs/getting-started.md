# Getting Started

Welcome to Awesome Web Agent Ecosystem.

This repository helps developers discover tools and standards for building AI-powered web workflows.

## Finding resources

1. Start with the [main README](../README.md).
2. Choose a category that matches your use case.
3. Open the official project or documentation link.
4. Review setup instructions, permissions, compatibility, and licensing.
5. Test integrations in a controlled environment before granting access to sensitive accounts or data.

## Choosing the right category

- Need to connect an agent to external tools? Start with MCP Servers.
- Need an agent to operate a browser? Start with Browser Agents or Browser Automation.
- Need reusable agent instructions? Start with Agent Skills.
- Need browser debugging? Start with Browser DevTools.
- Need to retrieve website content? Start with Web Research and Extraction.
- Need to validate a web application? Start with Testing and Quality.

## Safety

Treat browser agents and external integrations as software with potentially significant access.

Review permissions, credentials, network access, data handling, and project trustworthiness before installation.
