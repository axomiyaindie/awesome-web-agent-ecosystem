# Glossary

A practical glossary of terms used throughout Awesome Web Agent Ecosystem.

| Term | Meaning |
|---|---|
| AI Agent | A software system that uses an AI model to plan and perform tasks through tools or other capabilities. |
| Agent Skill | A reusable package of instructions and supporting resources that teaches an agent how to perform a task. |
| Browser Agent | An AI agent capable of interpreting and interacting with browser-based interfaces. |
| Browser Automation | Programmatic control of browser actions such as navigation, clicking, typing, and testing. |
| CDP | Chrome DevTools Protocol, used to inspect and control Chromium-based browsers. |
| Crawl | The process of systematically visiting pages and collecting information from websites. |
| Extraction | Turning website content into structured or machine-readable information. |
| MCP | Model Context Protocol, a standard for connecting AI applications to tools and data sources. |
| MCP Client | An application that connects to MCP servers and uses their capabilities. |
| MCP Server | A service that exposes tools, resources, or prompts through MCP. |
| Prompt | Instructions or context supplied to an AI model for a particular interaction. |
| Tool Calling | A model capability that allows an AI application to invoke external functions or services. |
| WebDriver | A standard browser automation interface. |
| WebDriver BiDi | A bidirectional protocol for browser automation and communication. |

This glossary is informational. Refer to official specifications for normative definitions.
