# Security Policy

## Scope

Awesome Web Agent Ecosystem is a community-curated directory of external tools, projects, integrations, protocols, and documentation.

This repository does not develop, operate, or maintain most of the listed resources. Security vulnerabilities affecting an external project should be reported directly to that project's maintainers through their official security reporting process.

Listing a resource does not imply that it has been security-audited, verified, or endorsed by this repository.

## Reporting a Security Issue

If you discover a security vulnerability affecting this repository itself, please do not disclose sensitive exploit details through public GitHub issues or discussions.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainers privately through GitHub.

When reporting an issue, include:

- A concise description of the vulnerability.
- The affected file, configuration, or workflow.
- Reproduction steps, where safe to share.
- Potential security impact.
- Any suggested mitigation, if known.

Please allow maintainers reasonable time to investigate and address the issue before publicly disclosing sensitive details.

## Safe Use of Listed Resources

Before installing an external tool, running an agent, or connecting an integration:

- Review its source code, dependencies, and release history.
- Understand the permissions and access it requests.
- Avoid exposing credentials, API keys, or sensitive browser sessions.
- Use scoped credentials and least-privilege permissions wherever possible.
- Review its data-handling practices and network behavior.
- Check its license, maintenance status, and security advisories.
- Test unfamiliar tools in isolated environments when appropriate.

## Disclaimer

Maintainers make no guarantees regarding the security, reliability, or behavior of third-party resources listed in this repository.

Users are responsible for evaluating and securing the tools and integrations they choose to install or use.
